JOSEPH J HOME IMPROVEMENT — GITHUB PAGES

1. Upload index.html, style.css, script.js and the images folder to your GitHub repository.
2. Replace YOUR PHONE NUMBER and YOUR EMAIL ADDRESS in index.html.
3. Replace YOUR_EMAIL_HERE in the form action with your email address.
4. Add your own photos into images/ using these names:
   hero.jpg
   statement.jpg
   about.jpg
   project-1.jpg
   project-2.jpg
   project-3.jpg
   project-4.jpg
5. Commit changes.
6. Open Settings > Pages and make sure GitHub Pages is deploying from your main branch/root.
7. Wait a few minutes and hard-refresh the website.

The site uses Google Fonts, Font Awesome, and AOS from CDNs, so there is no plugin installation required.
